The key forms and methods covered in this learning lab.

VARIABLE SEPARABLE
dy/g(y) = f(x) dx

Separate the variables, then integrate both sides.

LINEAR STANDARD FORM
dy/dx + P(x)y = Q(x)

Identify P(x) and Q(x) before solving.

INTEGRATING FACTOR
IF = e∫P(x) dx

Multiply every term by the integrating factor.

GENERAL SOLUTION
y · IF = ∫Q · IF dx + C

C is the constant of integration.
